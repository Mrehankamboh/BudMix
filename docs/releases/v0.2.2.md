BudMix 0.2.2 — preview. Hear your laptop and your phone in the same Bluetooth buds on Windows 11. Cast sound now works without typing a command.

## Download

| File | What it is |
|---|---|
| `BudMix-0.2.2-windows-x64-setup.exe` | Installer for your user only: Start menu entry and uninstaller, no admin prompt |
| `BudMix-windows-x64-setup.exe` | The same installer under a fixed name, used by the site's download button |
| `BudMix.exe` | The app as a single file, no installer |
| `SHA256SUMS.txt` | Checksums for all of them |

The build isn't code-signed: the first time, Windows shows *"Windows protected your PC"*. Click **More info → Run anyway**. On a PC with Smart App Control on, Windows blocks unsigned apps.

## What's new

- **One click for cast sound:** when a phone casts and Windows Firewall would stop its sound, BudMix opens and asks. Press **Allow sound** and say Yes to Windows. No command needed. The same button is in the setup check.
- It also clears a block left behind by pressing Cancel on Windows' own firewall prompt.
- **Cast works on any network:** BudMix no longer turns its receiver off on a Public or unknown network, so nothing needs to be changed on a new Wi-Fi. On public Wi-Fi, people nearby can see BudMix in their Cast list; a new phone only plays after you allow it on the laptop.
- Bluetooth needs none of this.

## What the Allow button changes

It adds two firewall rules for BudMix.exe only: one for Private networks, and one for the direct Wi-Fi link to the phone, which Windows treats as a Public network. That second rule accepts devices on the same local network only, and it also applies on public Wi-Fi.

## Installing over 0.2.1

Quit BudMix from the tray, then run the new installer. Settings and allowed phones are kept.

## Known issues

- **Two phones on Bluetooth:** both can connect, but when both play at once the sound can break up. One phone playing is fine. This is still being looked into.
- **Phone over Bluetooth fails with error 0x8007001F** on some phones: disconnect the phone from your buds, then turn Bluetooth off and on, on the laptop and on the phone.
- Hardware testing is still in progress; see `docs/HARDWARE_TESTING.md`.
