First preview of BudsLink: laptop and phone audio in the same Bluetooth buds on Windows 11.

- Buds: auto-connect and reconnect, buds as the default output with the previous output restored, test beep, call-mode (HFP) warning.
- Phone over Wi-Fi: built-in Miracast receiver ("BudsLink" in the phone's Cast list), approvals with an allowlist, phone screen window.
- Phone over Bluetooth: automatic fallback; Auto mode never plays the same phone twice.
- Per-source volume: buds, laptop, phone over Wi-Fi, phone over Bluetooth.
- Setup check with one-click fixes; diagnostics; demo mode.

Unsigned: Windows SmartScreen asks once (More info → Run anyway). See README → Known limitations.
